# StyleCart

StyleCart is a simple e-commerce website developed using Python and Django.

The project allows customers to browse products, view product details, add products to a cart, place orders, and check their previous orders. It also includes a separate admin panel for managing products, categories, and customer orders.

## Features

### Customer Side
- Customer registration and login
- Browse available products
- View products by category
- View product details
- Add products to cart
- Increase or decrease product quantity
- Remove products from cart
- Checkout and place orders
- View order details
- View previous orders

### Admin Side
- Separate admin login
- Admin dashboard
- Add and manage products
- Upload product images
- Add and manage categories
- View customer orders
- Update order status
- View basic project information such as total products, categories, customers, and orders

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- Django Sessions
